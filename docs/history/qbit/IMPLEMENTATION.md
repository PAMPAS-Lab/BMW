第二阶段原边界依赖审计及处理原则（下表描述扩展前的限制）：

| 边界 | 当前落点 | 后续处理原则 |
|---|---|---|
| 整片180秒/24分镜 | composition-contract、studio-contract、video-document、Studio发现参数、质量报告中的全片时间与分镜序号 | 统一受限常量与文档新版本；旧版本继续拒绝超出其能力的内容 |
| 旁白180秒、ASR区间180秒 | narration与speech契约、scene音频实测、voice source时间 | 保留单源/单次区间边界，不跟随整片长度放大 |
| 全片与局部图层时间 | composition-layers的start/duration/fadeWindow及编辑投影 | 全片时间可覆盖新长度；局部仍不得越过实际镜头，分割沿原效果时钟 |
| 音频内存 | composition-audio先分配完整48kHz立体声缓冲；Studio预览共用完整混音 | 改为有界窗口/流式消费，避免720秒完整PCM常驻；保留全片增益、旁白避让与连续原声 |
| 画面与素材内存 | composition逐帧编码、LinearFrameReader；素材原始字节总量256 MiB | 保持逐帧释放及来源总预算，不靠扩大所有素材内存限制实现长片 |
| 作业与输出 | CompositionProcessor十分钟超时、ArtifactJobIO有界输出 | 根据真实长片编码验证确定明确作业预算，取消仍等实际worker退出，下载512 MiB上限不变 |
| 审片 | 每镜24个关键状态、全片576点、实际MP4每次8图 | 对更长分镜列表保持有界分页和遗漏数，不能把固定总点数冒称全片连续语义覆盖 |

第二阶段实现设计与验收范围：

- 新增长篇文档能力版本，共享整片720秒、至多96分镜的受限常量；单分镜仍至多60秒、单旁白源/识别区间仍至多180秒。旧能力版本不能承载超出原预算的文档，不能通过导入绕过版本约束。
- 混音准备阶段只保存来源、全片时钟、实测旁白时长/峰值和包络信息。以至多4秒48kHz双声道PCM窗口消费原声、独立音轨及旁白，源音频仍按原始PTS映射；不分配720秒完整AudioBuffer。
- 全片峰值通过窗口扫描取得，编码与预览使用同一个增益。相邻未改变的切分保留来源和淡变原时钟，窗口切换不重新触发旁白避让或音乐淡变。需用窗口边界前后样本与原短片混音作数值对照。
- 导出按窗口与视频帧交错送编码器，Studio仅排程有限前瞻音频窗口；seek清理旧排程，再从全片时间恢复。取消等待解码、排程与输出实际结束。
- 以S07/S09/S10长度分别验证三份实际MP4及重开工程；补充720秒边界、跨段字幕/图层/原声/淡变、稠密分镜预算、旧文档拒绝、输出预算和取消测试。没有实际验证前不发布96分镜或长片完成声明。
