# AK 参考视频的能力增量设计

状态：2026-10-17，待设计／实施。依据为 [AK 十条视频研究](../research/AK_X_VIDEOS.md)，全局优先级统一维护在 [NEXT_STEPS](NEXT_STEPS.md)。原调研此前仅在本机报告中，本次将其技术建议纳入路线图；本页不是功能发布说明，不宣称已复刻十条视频。

## 第一批：三个可独立验收的技术切片

### AK-01 有界事件状态联动

代表片段：A01 的 17–32 秒 TEXT→LATENT→TOOL→TEXT 与记忆条，随后复用 A02 两轮状态切换。已有 scienceState、图层关键帧、源时钟与句锚继续使用；新增的是同一事件表驱动多个有限对象，不能把现有 flow 路径动画称为完整状态机。

候选设计：事件只包含稳定 ID、显式时间、有限目标 ID、闭合状态枚举／值，不接受代码、表达式、任意选择器或回调。首期先支持节点高亮、阶段标签、记忆条和代码行标记所需最小子集；token 排布与复杂代码富文本后续扩展。状态按保留时钟纯函数派生，逆序 seek 不依赖播放历史。源时间、演示时间、指标时钟分开命名，只有明确映射时才联动；不把 count-up 数字直接当作真实计时。

代码落点：`media-native/science-spec.ts` 与共享 painter 定义数据和显示，`feature-video/video-edit-contract.ts`、文档契约和 Studio 提供有限编辑。若需持久字段，先确定最低文档版本和迁移，现有 2.9 未自动获得新字段。所有动作仍由唯一 browser 的闭合目录发布。

退出条件：同一事件在顺序播放、逆序定位、整镜头剪切及导出时得到相同状态；无效目标／重复 ID／超预算被拒绝；改旁白或源区间后依赖失效可解释，不能偷偷认领旧绑定。验收 A01 机制段和 A02 两轮复用，保留可编辑文档、关键状态图与实际 MP4；此项不要求实现论文中的 Agent、游戏或机器人运行时。

### AK-02 科研图表增量

代表片段：A04 的 58–72 秒散点／对数轴，补充 A01 结尾的分组绝对值柱图；后续扩展 A09 的多系列曲线与排名。现有 ratio 的 bar 表示比例分配，不能当作多个独立测量值的柱图。

候选设计：在 `media-native/science-spec.ts` 旁增加有界、闭合的测量数据类型，明确序列、单位、基线、域、轴类型和来源。首期限定绝对值／分组柱图与散点的线性／对数轴；非正对数值、缺失来源和超量数据的处理必须明确，不隐式改数。多系列曲线、直方图、区间和阈值标记按后续样片补充；雷达图仅 A05 明显需要，放第二批。

退出条件：数值、轴标签与画面同源；线性／对数映射有独立预期值核验；手机可读，图例不混淆，空值与越界不伪造；实际预览和导出关键状态一致。结合 AK-01 检查 A04 的 3 倍速游标与区间映射，不能把片中 61 分钟案例误写成必须新增 61 分钟成片能力。新增契约、绘制和 Studio 测试与样片共同验收，已有 science 测试不能直接覆盖新图表。

### AK-03 受限预合成与代理素材

代表片段：A03 的 31–38 秒 16 格游戏墙，再用 A07／A09 的 5 路对照验证复用。4 路限制适用于视频叠加层，主画面另行解码；5 路先评估主画面加 4 层是否满足布局，不能仅按总路数认定超预算。保持同时最多 4 个视频叠加解码器、单容器 8 视觉层与全片 64 独立对象；先通过分批中间片得到可控的合成素材，不直接提高全局预算。

候选设计：`media-native` 执行有界批次，`feature-video` 保存 Project 拥有的显式配方与结果关联。缓存身份至少包含素材 SHA、源区间、速率、布局、尺寸、帧率和渲染版本；明确中间片原声保留／静音策略，避免素材墙叠出多路噪声。最终片是普通受控素材，保留原素材和可重建配方；能够重建不等于在成片中直接编辑每个内部对象。

退出条件：16 格样片可按配方重建，修改一个输入使相关结果失效；源区间和同步经关键帧核对，音频策略可检查。记录实际分辨率、帧率、用时、峰值资源与磁盘预算；缺失素材、取消、失败和 Project 切换必须等待真实 worker 清理，清理失败维持隔离，不能留下半成品充当缓存。先运行小规格，再单独测目标规格；此前长片结果不能替代本项性能验收。

## 实施与关闭规则

上述字段和接口都是候选设计，尚未发布。先完成各切片契约、预算和样片设计再实现；Project／Session 归属、revision CAS、FIFO、取消清理和官方 Agent 循环不变。外部结果通过受限浏览器动作和原生媒体边界进入 Project，不向模型暴露 shell、通用文件系统或任意 HTML。

实现后更新 FUNCTIONAL_SPEC、专题 Schema／文档、动作发现和测试目录；新增测试运行 docs:features。build、check、unit、boundaries 及相关 Studio／media／video／narration 回归与样片内容验收分别记录。现有测试只能证明其已覆盖的能力，新增切片需要自己的失败路径与结果证据。研究已完成可保留为依据，未完成增量不得随研究归档一起关闭。
