# YOUTUBE-01：真实站点原生音视频获取

状态：2026-10-29 优先完善中。原生有限点播获取已实现，有短样本完整解码与94分钟 GTC 整片保全记录；网站验证、页面身份误判与网络中断仍需完善。保留 HTTP/HLS，不引入 yt-dlp，TikTok 不属于本期目标。

## 当前实现与证据

同目标完整直链继续由原生浏览器网络适配与 Mediabunny 处理。只有 SABR/UMP 的目标，复用当前播放器实际发出的有界原生 POST，以同页、CPN、config、视频 ID 与格式版本绑定，使用固定版本 `googlevideo@5.0.0` 接收编码分段，再原生复制两轨编码包封装。没有地址猜测、签名解密、外部下载器或录制替代。

有限短片的制作入口已增加 `library.sources acquire method:auto`：同一确认目标优先保全观察到的分发，至多两个不同候选共享60秒预算；只有失败并实际排空资源后才原生采集同一播放器，失败清理/身份变化/取消不能转入兜底。采集前有界缓冲与画质选择，采集仍重编码，实际尺寸/音轨/完整范围须独立核验。2026-10-25授权实际制作的Microduck `zHBrUVyQJWc` 用auto在17.362秒成功保全1080p H.264和英语双声道AAC，未使用兜底；详细范围/哈希及局限见[续验记录](../research/SOCIAL_DOWNLOAD_VALIDATION.md)。单次成功不消除其他验证或网络失败，也不是十分钟全流程验收。

公开样本 `jNQXAC9IVRw`：19.064秒、320×240 AVC＋44.1kHz双声道AAC，最新原生获取合并1.331秒；`a9LDPn-MO4I`：60.047秒、1920×1080 AVC＋同规格AAC，最新98.802秒。两者已核目标身份、原始轨道 SHA、每轨包数／负载 SHA／PTS、分段完整覆盖、全片双轨解码与首中尾画面；人工听感未做。速度受网站等待与网络影响，不能保证快于实时录制。

约10分钟样本 `aqz-KE-bpKQ` 首次149.029秒遭网站流保护验证拒绝；复测验证允许接收，但796.930秒发生协议网络中止。两轮部分文件均已清理，不计成功。后续94分钟 GTC 目标已完成整片双轨保全、packet-copy合并与包级连续性核验（1,585,654,747字节、5637.7353秒），但未做连续全片解码或人工听审；不能外推任意长片。Host派生POST Origin，受限刷新仅接受同页、原CPN、config、client和选定格式不变的后续真实请求；最多3次、各15秒等待窗口，不生成或破解验证值。刷新成功／跨身份拒绝由隔离夹具核对；十分钟样本的失败记录保留。

## 当前完善范围

2026-10-29吞吐定位已完成节点对照。原慢链路的Microduck／UHD原生采样仅21.6／18.2 KiB/s；相同真实轨道的离线worker／双轨写入／packet-copy／包级核验仅0.503／0.723秒。用户切换出口后，同一冻结产品源码在当前JMS-S1完成整片获取合并17.696／18.852秒，均全片双轨解码通过。另用独立临时mihomo实例逐个测10个节点的相同YouTube公开资源4MiB范围，前三个完整候选各复测一轮；所有完整范围SHA相同。S801两轮约1072／1198 KiB/s，S5约1067／1034 KiB/s，MacMini-Reality约14 KiB/s；S2波动明显。S801真实Microduck下载5.796秒，UHD首次长诊断后唯一播放器准入失败且无产物，保留该失败后，新页面单条补测4.367秒并全片解码通过，不能混作同次2/2。四个新成功产物的原编码AVC/AAC轨道SHA与此前验收完全一致，没有降画质或放宽身份。主要瓶颈进一步定位为出站节点／出口／CDN链路差异，不是本地mihomo或BMW的通用吞吐上限；不能断言旧轮使用哪个节点，也不能再细分远端限速与上游路由。建议本轮YouTube优先候选S801、S5为仅资源测速的备用；手动默认S1未改。全部临时代理进程与私有配置已清理，下载实现及HTTP/HLS／身份／超时／清理机制不变；完整轮次、初始失败、单条补测与局限见[吞吐诊断](../verification/YOUTUBE_THROUGHPUT.json)。

每Project一个Agent专用YouTube工作标签与串行整任务租约已实现。用户标签独立，工作页不被普通LRU回收，切换Project暂停保留，关闭/归档等待实际销毁；取消与失败清理隔离继续生效。优先实际站内链接/搜索，站内尝试至多30秒且计入总预算。常驻页首次初始化180秒，后续90秒，YouTube外层200秒；完整文档不再因播放器或可见控件提前stop，避免中断应用脚本/事件绑定。搜索组件先取yt-searchbox，再取form，兼容按钮在内部form之外的现有网页结构。简单watch目标整页加载后先由真实网站界面重新激活同目标，再短暂静音播放/切换已公布画质，让网站自行取得流验证；不生成验证值。媒体工作/清理未结束时拒绝新导航。临时后台采集页仍按轮次清理，不转为永久页面。

本轮恢复后，固定三个目标均完整取得分发原编码轨道、packet-copy合并并全片双轨解码：`jNQXAC9IVRw` 320×240／19.064秒／741,237字节，获取合并36.726秒；`zHBrUVyQJWc` 1080p／28.305秒／9,321,725字节，793.713秒；`a9LDPn-MO4I` 1080p／60.047秒／20,799,322字节，2117.098秒。全部首中尾目视核验；前两条全音轨PCM无缺样且非静音，第三条原始AAC全静音，八个窗口与交付MP4的PCM哈希逐一一致，无缺样。人工听感未验收。

序列目标就绪为148.823／43.723／5.195秒：第三条真实搜索SPA保留文档，Microduck因isUnlisted搜索不命中，整页回退后首页/历史激活161毫秒。第三条在该序列中被另一处独立重启终止，最终文件由同一公网代码快照单条补测，补测冷加载102.255秒另记。最终检查快照还包含语义参数保护、单调进度计时及并发通用播放器修复；135组离线、14组原生检查通过，版本差异独立登记。三个成功外网传输本轮都未发生重传；慢重传超过30秒与无数据仍30秒超时由真实worker回归验证，不冒称本轮外网断线恢复已验收。详见[本轮完整报告](../verification/YOUTUBE_WORKTAB_RECOVERY.json)。本机当前网络吞吐很慢，HTTP/1.1兼容模式成功不能外推任意网络或默认协议速度。

2026-10-29前一轮三样本对照采用相同HTTP/1.1设置、独立临时未登录配置及固定顺序：新标签目标就绪26.8/4.5/19.4秒，常驻标签30.1/13.8/18.4秒。导航均3/3；常驻后两次实际均为整页回退，文档未保留；下载均0/3，失败为网站流验证。不能将常驻视为消除超时或认定提速。早期常驻组有一条短片双轨保全/全片解码成功，与最终对照分开记录。详见[工作标签验收](../verification/YOUTUBE_WORKTAB_VALIDATION.json)。
