## 已确认的缺口

本轮公开样本 `jNQXAC9IVRw`、`a9LDPn-MO4I` 的页面、播放器与响应视频 ID 一致，但当前响应没有可用的完整音视频直链，实际播放使用 SABR/UMP。一个完整文件候选返回 HTTP 403，不能将播放器请求中的 UMP 响应作为完整文件合并。YouTube 本轮接受数为 0/2；同轮 X、微博各 2/2。详见[真实链路验证](../research/SOCIAL_DOWNLOAD_VALIDATION.md)。
