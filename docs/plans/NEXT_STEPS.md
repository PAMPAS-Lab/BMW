## 第一批可评审交付：写稿与解释

先用现有 preparation.notes／outline 保存可读过程稿，不扩展数据格式。每段至少回答：受众要解决的问题、依据是什么、观众看哪里、台词与源区间如何对应、何处留观察时间、结尾得到什么判断。研究全量与主片选择分开；无法支持的台词先改稿，不用装饰图掩盖证据缺口。

产物为旧／新稿、同素材镜头表、来源与限制、实际旁白时长、两版 MP4 及当前指纹审阅。采用相近时长、同题材比较，保留用户对具体段落的评价；解释片增加核心问题复述和一个条件变化的预测。没有用户反馈时状态为待内容验收，不能根据帧数或技术通过结项。

CONTENT-02 在这份评价标准之后试验。指导内容只描述创作方法与现有动作的映射，记录来源版本和停用办法；目录验证、权限与动作 Schema 仍由 Bridge／harness 决定。先比较效果，再决定是否新增原生的版本化指导读取入口。

## 第二批技术切片：只读制作影响计划

建议先在 `feature-video` 的 readiness／service 旁实现纯派生计划，不持久化第二份草稿。以下字段是**候选设计，尚未发布到 browser Schema**：

| 候选部分 | 数据与约束 |
|---|---|
| 输入 | 可信 Project／Session、draftId、expectedRevision；可选已有 VideoEdit 试算，不接受路径、owner 覆盖或任意表达式 |
| 基准 | 当前 revision、内容签名、实际素材身份／已有 SHA、设置指纹和渲染版本；消费前重新读取事实 |
| 结果项 | 稳定镜头／对象 ID、keep/rebuild/rebind/review、原因代码、受影响的旁白／句锚／字幕／成片；建议每页至多20项，沿用分页机制，最终预算经实现评审确认 |
| 整片决定 | 可复用既有 MP4，或需重新编码整片；封面独立判断；不承诺局部编码复用 |
| 失效 | revision、来源或设置变动即 stale；重新计算，不自动执行、不预约队列、不重发输入 |

`media-native` 提供素材事实，`feature-video` 解释编辑影响；`browser-capability` 仅在闭合契约验证后发布受限发现入口。官方 Agent 读取计划后仍使用既有修改／配音／制作动作，各动作重新执行 owner、CAS、FIFO、Project 排除和取消清理检查。计划不是批准、执行回执或可绕过校验的 token。

最小影响矩阵：

| 改动 | 预期影响 | 必须保留 |
|---|---|---|
| 一镜头改一句旁白 | 该镜头旁白待更新；重新配音后该音频上的全部旧时间证据失效，相关句引用需重绑 | 其他镜头旁白、独立人工字幕／译文、旧成片 |
| 只换一张图 | 相关源区域／阅读目标失效，视频重编；未改音频保留 | 其他素材、原图与来源记录 |
| 只改独立字幕 | 布局重查、视频重编；旁白不重做 | 原音频、有效句锚、其他字幕 |
| 只改封面 | 封面重制，视频指纹按现有规则复用 | 已验证 MP4 |
| 来源文件或配置变化 | 返回明确 stale／重查理由，执行前按当前事实重算 | 历史证据不伪造、不改写 |

先验证该矩阵和取消／冲突，再接 CONTENT-05。语义关系仅指向现有卡片、阅读或聚焦目标，由有效句锚派生实际时间；重复句、换旁白、删除对象不能自动认领旧绑定。需要新增持久字段时先定义最低文档版本、迁移和无损往返；不要预先宣称 2.10 已实现。

## 图文长篇的独立设计边界

候选文章对象由 Project 拥有，保存稳定文章 ID、revision、创建来源 Session 与可追溯媒体／引用；跨 Session 编辑权限需明确设计，不照搬 Studio 的私有草稿规则或默认为全体可写。首期内容限标题、章节、正文、图片／视频引用、图注、比较表和来源，输入为闭合结构。

候选首期输出为受控阅读页和 HTML＋本地素材包，Markdown 与素材清单作为可选导出；不接受任意 HTML 导入，不包含 PDF／DOCX／CMS 发布。先做引用缺失、素材变化、长表、移动端、离线链接与并发修改原型验收，再确定 schema 和正式 browser action。现有 Project 文档、notes 或开发侧 HTML 不能充当该能力已完成的证据。

## 验收与文档同步

每个技术切片先跑相关契约及隔离原生专项，再完成 build、check、unit、boundaries 和仓库要求的相关 DSH／desktop／Studio／media／video／narration 检查；构建串行，测试只用一次性数据目录。新增测试同步生成清单。付费模型、外部服务、真实自然 ABR 与用户核听分别授权、分别记录，离线结果不覆盖它们。

结项时将实际字段写入 FUNCTIONAL_SPEC／专题规范，阶段证据归档，并从本表移除已完成增量；剩余质量项保留稳定 ID。下一次完整回归须使用当时源码哈希，不能将已完成的三方对齐误写为已实现这些创作计划。
