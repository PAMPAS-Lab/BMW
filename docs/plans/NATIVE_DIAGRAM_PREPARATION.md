# 新闻动态图解的准备证据

状态：已实现受限原生末镜取帧与私有journal；仅 `kind: diagram` 声明仍不能放行。首0–3秒连续真实拍摄要求不变；纯文字、装饰动画、静态图片推拉不属于用户确认的动态图解。

## 目标与现有缺口

用户允许末几镜使用有来源、有信息推进的原生动态图解。应检查真实可编辑对象、推进时间及实际画面，不能由 `animated: true` 等模型声明替代。

现有 `media-native/science-spec.ts` 提供封闭的图解数据结构与 `scienceState(spec, localTime)`；Studio 预览和 MP4 导出共用原生 painter。它们能表达数据、关系和变化，但存在以下证据缺口：

- `prepare-reference` 只读取 Project 的 image/video artifact；`StudioReferenceRecord` 必须绑定该文件的 ID、SHA 和取帧记录。原生 diagram 层本身没有源视频文件。
- GUI 预览没有可持久验证的“Project/Session/draft/revision、scene、localTime、compositionHash、PNG SHA”回执。通用截图看过画面，不能证明它就是当前镜头和指定时间的原生预览。
- `video.cover` 只从既有图片/视频取画面；不能作为图解对象的渲染证明。
- 当前新闻准备要求存在实际素材，并要求末两镜主视觉为已观察的真实视频；直接把 diagram 枚举加入末镜允许列表，会缺少真实画面观察与版本绑定。

当前新增prepare-diagram/read-diagram，复用原生导出painter短暂编码后取三张PNG并清理中间视频；只向模型返回准备图像，不能登记为成片。

## 可实现的最小证据链

1. **受限原生逐态取帧。** 在现有唯一 `browser` 的 Studio 能力内增加封闭的准备操作，显式传入当前 draftId/expectedRevision、单个 sceneId、最多三个局部时间。Host 选择当前真实场景及受限原生 diagram 对象，使用与预览/导出相同的 painter；禁止 HTML、脚本、URL、任意文件路径和任意渲染程序。输出 Project 所有的 PNG，不能作为最终成片登记。
2. **不可伪造的准备记录。** Host 私有 journal 固定归属、草稿内容指纹/rendererVersion、scene、有效图解对象、精确取帧时钟和每张 PNG SHA。取帧前后检查 Project/Session/revision、源文件 pin 与任务取消，清理完成后才释放 FIFO。Agent 不得通过 draft.update/import/restore 注入这些回执。
3. **检查真正的信息推进。** 限制为实际 native diagram 的数据/关系对象。检查可见对象与覆盖时段、在所选局部时间的实际 `scienceState` 差异，以及推进是否落在本镜播放窗口内。静态状态、仅文字/容器位置或透明度变化、纯装饰粒子均不满足。Host 只证明结构和状态变化，不判断新闻含义正确。
4. **绑定原始证据。** 每个数值、比较、路径或关系必须由当前草稿精确引用支持，区分真实数据、承诺和说明性示意，保留来源链接与发布日期。不能把演讲者对未来的陈述画成已交付结果；无可核依据时返回具体缺口。
5. **逐态观察声明。** `read` 返回实际 PNG；Agent 看过入口、推进/主态及退出后，提交具体对象变化、与新闻论点的关系及可读性观察。记录为 Agent 声明；不自动填写“已观察/相关/事实正确”，不转换成用户批准。
6. **准备门禁与独立内审。** 只有末镜可以走该原生图解证据分支；首三秒仍按真实拍摄检查。图解数据、时间、取景、文字、来源或源文件改变即使记录过期。导出后的当前 MP4 仍须全镜关键态及独立整片审阅，技术检查、模型意见与待人工听感分别记录。

原生对象的结构检查通过，不等于图解有信息价值；PNG 不同也不等于新闻事实成立。最终语义与展示质量仍由有证据的 Agent 观察、独立 BMW 审片及用户验收承担。

## 所需代码边界与最小验证

- `media-native`：封闭单镜取帧契约、同 painter 的原生处理、Project PNG 输出、预算与取消/清理；不能新建模型可用 shell/IPC。
- `feature-video`：准备请求/回执及私有证据 journal，复用当前 revision CAS、来源引用检查和真实图片读取；不能把模型提供的 compositionHash 当作可信回执。
- 浏览器目录与功能规范：声明仅准备证据，不导出视频、不认证语义，明确允许的 diagram 种类与预算。
- 回归：真实数据变化与三态画面绑定；静态状态/装饰动画/过期时间窗口拒绝；草稿或 PNG/源文件替换、跨 Project/Session、用户编辑并发、取消与清理失败拒绝；首三秒仍拒绝图解；最终导出与审片不被跳过。原生夹具须使用临时 Profile，不能冒称付费模型或生产审片覆盖。

实现范围为末镜1–10秒、单个全时段原生diagram、无外部媒体与全片叠层；原生状态推进及三帧实际画面均验证。当前保留一条私有同镜证据，旧对象变动需重新prepare。独立审片和具体任务生成授权仍独立执行。
