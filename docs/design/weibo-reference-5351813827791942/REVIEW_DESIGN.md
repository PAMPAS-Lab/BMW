# 简洁卡片模板体系：更新版设计与取舍

日期：2026-10-09。本版承接 [详细模板设计](TEMPLATE_SYSTEM_DESIGN.md)，说明分类、创作规范、交互和实施顺序。第一批已有实现及 45 秒八类样片；验收证据见 [样片记录](../template-sample/source-plan.json)。后两批仍为提案。

本轮追加了 [每秒两帧调研](DENSE_RESEARCH.md) 与 [设计增量](DENSE_DESIGN.md)：265 个实际样本全部复核。新增模板仍为提案；本轮不修改已交付应用。新增优先级、字段和验收以设计增量为准，原先分批规划作为背景保留。

## 设计决定

采用 **八类内容卡 + 少量版式变体 + 六种受限表现 + 全片统一风格**。

类别回答“观众应看懂什么”；变体回答“内容怎样排”；表现回答“怎样出现”；全片风格管理品牌、栏目标题、画幅和字幕。不同维度分开，避免出现“动态数字截图对比卡”等越来越长的类别。

每类先一个推荐模板，用户通常只填写二至四项内容。模型先选择表达任务，再读取该模板规范；不需要学习坐标、字体、层级或动画曲线。每张卡仍用原草稿内容，不维护模板专用正文副本。

## 参考画面分类

本地参考视频为 132.19 秒、720×1280；[原始分析](DESIGN.md) 记录下载、轨道及哈希。本轮按每秒两帧获取并复核 265 个样本，取样 PTS 为 0、0.5……132 秒；原尺寸细节与逐段索引见新增调研。未建立精确逐镜头切点或完整音频转写，不能据此断言完整镜头数量。

| 参考位置 | 观察到的画面 | 建议分类 | 不应混淆的事项 |
|---|---|---|---|
| 多数抽样 | 深灰背景、顶部三行新闻标题、下方字幕 | 全片资讯风格 | 三行标题不是“三要点卡”，不在每卡复制 |
| 开头约 3–5 秒 | 文档背景上的“722篇”等数字变化 | 数字强调 | 数字和单位结构化；曲线无需复刻原片 |
| 8、48、112 秒附近 | 文档、帖子和重点段落 | 证据：截屏/引用 | 重点标记的制作来源无法仅凭成片确定 |
| 40、52、56 秒附近 | π、箭头、范围及阈值图 | 图解：关系/范围 | 含比较关系的图片不等于两项文字对比模板 |
| 开头及中段 | 光环、飞纸、人物、工业设备短片 | 素材：情景/人物 | 卡片播放素材，不承诺生成所有复杂动画 |
| 113.5–121 秒 | 文档上叠加人物、身份与引述/译文 | 证据：人物引述变体 | 新增固定人物槽；不是任意独立层 |
| 95.5–101.5 秒 | 社交原文反白与中文内容逐步出现 | 证据：原文/译文变体 | 与底部旁白字幕分开 |
| 11.5–13、63–67.5 秒 | 大字关键词及逐处原句反白 | 标题强调＋证据重点 | 词句不是数值，反白不是自动 OCR |
| 连续文档样本 | 画面取景变化 | 证据/图解 + 聚焦 | 不能仅凭成片确定是录屏还是截图动画 |
| 尚无充分抽样证据 | 独立标题、三要点、真实连续鼠标轨迹 | 通用扩展类别或后续预设 | 不宣称参考片使用了这些模板 |

旧 [四秒分类抽样图](classification-sheet.jpg) 保留；本轮请用 [半秒联系表](dense-2fps/index.html) 并排核对；不把视频中的数学判断作为制作模板的事实依据。

## 八类目录与最小内容槽

| 一级类别 | 推荐模板 | 用户/模型主要填写 | 首批表现 | 后续变体 |
|---|---|---|---|---|
| 标题 | 标题 + 可选副标题 | 标题、副标题 | 静态、淡入 | 章节、结尾 |
| 要点 | 三个并列结论 | 标题、三项短句 | 静态、淡入、逐条出现 | 一至三项兼容列表 |
| 对比 | 两个对象的同维度差异 | 标题、两项内容 | 静态、淡入 | 前后状态、利弊；多维表格先用图解 |
| 数字 | 一个数值占据视觉中心 | 数值、单位、短说明 | 静态、淡入、计数 | 多指标另评估，不把数字卡扩成仪表盘 |
| 证据 | 原文截屏 + 短说明 | 素材、说明、来源 | 原画面、聚焦、轻推近 | 引用、可编辑重点 |
| 演示 | 实际页面操作录屏 | 视频、区间、可选聚焦 | 原视频、聚焦 | 二至三步说明、真实指针轨迹 |
| 图解 | 单张机制或关系图 | 图片、短说明、来源 | 原图、聚焦、轻推近 | 二至四节点线性流程 |
| 素材 | 一至八段顺序画面 | 图片/视频、顺序与时长 | 原素材；图片可轻推近 | 固定人物、姓名和背景槽 |

新增六个优先变体为：证据阅读、原句重点、原文/译文、人物引述、背景数字、关键词强调。图解随后补共同目标与范围关系；总览/细节先共享阅读配方。一级入口维持八类，详见设计增量。

“截屏标注”放在证据类，“录屏轨迹”放在演示类；“动效”是表现维度。截图展示操作时也可作为演示素材，但实际承载方式必须符合模板的媒体类型要求，不因用途名称而伪造录屏。

首批限制沿用实际契约：标题最多 44、单条要点 64、最多三项；数字非负、最多九位整数及两位小数、单位最多八个 UTF-16 单位。字符预算之后仍做真实排版校验。横屏对比左右排列，窄竖屏上下排列。只发布已验证画幅，不通过缩小文字无限容纳内容。

## 模型创作规范：先选任务，再填槽

每张卡的创作计划只需：**表达目的、模板、内容、素材缺口、旁白、事实来源**。动效和推荐时长由模板默认；只有叙述需要时才调整。

1. 从文章或脚本提取本卡的一个主要任务：引题、列点、比较、突出数值、展示依据、演示操作、解释关系、提供情景。
2. 按任务选类；必要时读取单个模板的字段、素材条件和一份有效示例。
3. 列出缺失素材并采集，填入原 scene 的标题/要点/素材/旁白；新增数字值等放入有限 cardSpec。
4. 校验数量、素材、来源引用和文字区域，再实际预览；错误指向具体槽。
5. 人只需改内容、换素材、换类、选择允许的表现，沿原 CAS 保存和撤销。

示例：“有一个值得记住的数量，并解释三个原因”应拆为数字卡和要点卡；“展示两方案在五个维度的差异”应采用表格图解，不能塞进两个长段落。普通作品无需用齐八类，也不强制模板比例。

模板规范区分硬条件与创作建议。三要点恰好三项、对比恰好两项、素材实际存在是硬条件；避免连续重复、推荐时长和推荐表现是建议。缺第三项不能补造事实；文字太长不能静默删除；缺图不能用占位图假装完成。

模板目录、模型说明、输入校验、GUI 控件和预览/导出采用同一可信定义。模型首次只看到八类摘要；详情按 templateId 懒读取，继续作为唯一 browser 的受限动作。模型不能提交 HTML、表达式或渲染代码。

### 再减少一层创作成本：段落配方

八类卡片解决单个画面选择，但模型仍需组织先后关系。建议在模板目录之上增加少量**创作建议配方**，只输出分镜计划，不增加编辑类别、数据格式或执行能力：

| 段落任务 | 推荐顺序 | 选择条件 |
|---|---|---|
| 解读一条资讯 | 标题 → 数字/要点 → 证据 → 图解/对比 → 要点 | 没有数值就不用数字；没有比较对象就不用对比 |
| 说明一个操作 | 标题 → 演示 → 证据/图解 → 要点 | 演示必须取得真实视频；截图不能冒充录屏 |
| 解释一个概念 | 标题 → 图解 → 对比/素材 → 要点 | 图解负责关系，素材负责情景，两者不互相替代 |

配方只在模型需要规划时提供，人可以直接改卡片顺序。不是另一套可编辑“配方对象”，也不强制视频使用全部类别。模型先选一个段落任务，再逐卡选模板，避免一次比较所有模板与表现组合。

每个模板的创作说明固定为六项：**何时用、何时不用、必填槽、允许表现、有效例子、常见修正**。例如数字模板：突出一个数量；范围/公式改用图解；填写数值、单位、说明；可选静态/淡入/计数；示例“44%”；若单位与说明不清，要求补充适用条件。有效例子仅示范结构，不提供可直接复用的事实结论。

默认表现应保守：初稿使用静态、原视频播放和必要的淡入；有叙述理由才启用计数、逐条出现或聚焦。这样增加画面可能性，同时避免模型每卡都添加动效。

## 简洁卡片交互

卡片显示类别名称，保留“编辑卡片”“换画面”“声音与字幕”三个主要入口。编辑卡片内展开内容槽；数字显示数值、单位、小数位，其他类显示对应的文字槽。表现方式折叠，仅提供该模板支持的选项。

“更换模板”先展示八个基础缩略样例，再按需展示变体。用当前卡内容预览，显示转换影响：三要点转两项对比不能丢掉第三项；素材转标题说明素材将不再显示但源文件保留；证据换图不能套用旧重点坐标。应用是一次可撤销保存，取消不改草稿。

全片标题、品牌、资讯/标准布局、字幕和旁白节奏只在原全片设置保存一次。点击全片标题定位全片设置，点击本卡文字编辑本卡。多画面和有限取景在卡片详情内展开；独立自由图层和音轨仍按原规则要求高级模式。

以数字卡为例，展开后的顺序是「标题 → 数值/单位/说明 → 表现方式（默认折叠）」。旁白、字幕仍进入原“声音与字幕”。模板选择页先展示八个带真实缩略预览的类别，不显示全部高级参数；选定类别才出现适用变体。不另加一套模板管理页面。

## 能力状态与取舍

以 FUNCTIONAL_SPEC 和当前源码为依据；当前工作区已有八类 cardSpec、目录、GUI、共享原生绘制和 2.1 codec 基础。资讯布局与紧凑新旁白已接入，并通过受控横竖屏导出和相关原生检查；已制作真实来源的八类样片，核对切割时钟、实际 MP4 动态/切换帧，并在用户解锁后通过原生文字命中、窗口尺寸和卡片拖动检查。旁白经实际音轨解码和本地识别检查，未声明完整人工核听；后两批尚为设计。

| 需求 | 建议交付方式 | 限制原因和取舍 |
|---|---|---|
| 八类选择、统一填写、有限表现 | 第一批完成并验收 | 已验证闭合边界、持久切割时钟及原生卡片编辑；旧内容保留 |
| 固定新闻标题、品牌、素材窗与字幕 | 第一批完成资讯布局 | 原标准模板位置不同；新增字段不能只接 UI 而不接导出 |
| 截屏框线和箭头 | 第一批生成标注 PNG；第二批可编辑三处以内重点 | PNG 内部不可独立修改；可编辑版需要坐标、素材身份和时钟契约 |
| 连续鼠标轨迹 | 第一批仅录屏播放/点击聚焦 | 当前记录没有连续 pointermove；真实轨迹需有界采样及帧映射，不能用点击连线冒充 |
| 图中节点、箭头逐步出现 | 第一批静态图或预制短片；第二批有限流程 | 现有图解图片没有独立节点语义；通用矢量编辑明显增加成本 |
| 人物与文档同屏 | 第一批合成图片/视频；第二批固定人物槽 | 独立人物图层不符合简洁模式；专用槽可控制复杂度 |
| 三维光环、飞纸、复杂情景动画 | 使用已有或单独制作的短片 | 模板体系负责承载，不具备通用三维/素材生成能力 |
| 紧凑旁白、句级字幕 | 第一批统一实测时钟 | 节奏设置只控制新旁白；已有人工剪切与字幕不能批量覆盖；不承诺逐字声学对齐 |

第一批不开放自由坐标、曲线、通用 HTML 或隐藏独立对象。全片仍保持 24 卡、180 秒及既有媒体预算。超量先合并同一段落内的顺序素材或拆作品，不借模板扩张资源和权限。

## 分批验收

第一批覆盖八类基础模板、统一目录、转换预览、资讯布局、紧凑新旁白和句级字幕。制作约 45–60 秒可编辑样片以演示全部类别；正式作品按内容选类，不以覆盖率作为创作目标。

每个模板验收有效/无效内容、横竖屏实际文字区域、预览与 MP4 一致、保存恢复、撤销、切割后动效不重启。旧文档保持原行为，高级对象不会伪装为简洁内容，后台修改遵守 owner/revision。新能力只在验收后进入有效模型目录。

认知成本单独验收：初稿创作只读取八类摘要与实际使用模板的详情；编辑一张卡只展示该类内容槽；更换模板无需打开高级编辑；校验失败只解释当前卡的具体问题。检查同一事实能否通过标题、证据、图解等合理方式表达，而不是用模板数量或强制八类覆盖衡量普通作品质量。

第二批只增加高频固定变体：引用、截图重点、人物和有限流程/步骤。第三批再评估真实轨迹及复杂素材生产。每个新变体必须说明新增哪些内容槽，不能仅因为某段参考画面漂亮就扩展一级类别。
