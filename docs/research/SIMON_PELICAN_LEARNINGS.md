# Simon Pelican 案例经验

依据 2026-10-15 至 16 的 V1/V2 调用账本、结果、制作说明和审阅记录提炼；不是对当前版本的复测，也不等于用户内容验收。V1 账本记录 814 次操作、11 次失败或拒绝；最终技术与审阅门通过。V2 记录 117 次调用、错误列表为空，技术和 Agent 画面审阅通过。两版用户验收均为 pending，模型未直接听到音频。

## 可用于改进的事项

1. **P1：创作目标和阶段预算。** V1 中研究经历约 500 次调用仍未产出影片，用户方向要求后才中止并重新排序。明确素材覆盖、结束条件、研究与制作的时间预算；区分运行成功、任务完成和用户接受，停止或中断的输入不自动重放。此为流程建议，不代表当前性能。
2. **P1：旁白分批与片长预检。** V1 三次因当时 180 秒合成上限拒绝，其中旁白错误返回完成场景与当前 revision，后续恢复。当前契约已扩至 720 秒／96 镜，不能将旧上限视为当前缺陷；仍应按实际语音时长、当前限制及版本冲突核对进度，不覆盖已完成音频。
3. **P2：错误可恢复与接口发现。** 历史记录中来源分页参数、空图形、未知编辑命令、点击未知字段及非公共来源 URL 被拒绝；这些是校验行为，不等于程序故障。帮助应指向正确操作和必要字段，修正后明确由用户或 Agent 决定下一步，不把拒绝算成已执行。
4. **P2：浏览器读取超时。** 两次 DOM observe 超过 15 秒；应记录阶段、范围和耗时，避免把超时当成来源不存在。是否仍可复现须在当前版本和隔离页面验证。
5. **P1：用户理解与视频多样性。** V2 从 V1 的说明卡调整为反差开场、鸟种→结构→运动递进，采用已有真实素材和短标签；V2 全 14 镜头审阅了 275 个关键状态。它只是一次具体创作实验，不能据此宣称叙事质量稳定；应记录为何选择、观众反馈及下一次变化，技术审阅与内容接受分开。
6. **P1：来源与媒介属性。** 区分帖子、传播和独立作品；记录模型版本、提示、迭代与未知项，不把静态图、镜头移动、代码动画和生成视频混为一类，不跨不同提示或预算做绝对排名。样本计数为 98 个记录组，不能称作 98 件去重作品。
7. **P1：声音与审阅边界。** 可播放、音轨指标和 Agent 抽帧不等于人工听审或模型核听；V2 字幕为编辑估时，发音与声画精确同步尚未被核听证明。每次对当前导出指纹完成场景和整片检查，人工结果单独登记。
