## 收录约定

- 每个专题单独保存为 Markdown 文档，并在本索引登记快照日期、整理日期、范围与证据状态。
- 使用统一比较维度，保留原始仓库及尽可能固定到提交的文档或源码链接。
- 分别描述作者说明、源码核对、样片实测和设计建议；失效、缺少执行器或占位实现保留在对应条目中。
- 区分研究候选与已实现功能。涉及 Project 归属、模型工具、媒体执行和权限时，说明与当前 BMW 契约的关系。
- 新的实测或结论变化注明日期；不把旧快照写成持续有效的承诺。
- 不在研究目录存放第三方可执行技能包、素材原件、运行缓存或凭据。
