## 收录规则

- 保留原始来源、快照日期和尽可能固定到提交的链接；本地能力映射单独标注核对日期与实现基线。
- 分别记录作者说明、源码核对、样片实测与设计推断；失效、占位或缺少执行器的条目保留限定，不改写为已验证能力。
- 方法进入规划时引用研究并对齐既有计划ID；实现与权限变化进入功能规格，历史验收仍绑定当时源码和环境。
- 不在研究目录存放第三方可执行技能包、用户素材、运行缓存或凭据。
