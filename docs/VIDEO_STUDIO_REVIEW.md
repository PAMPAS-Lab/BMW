# Video Studio 能力审视与提升规划

适用：BMW 当前实现，2026-10-04。功能边界以 FUNCTIONAL_SPEC.md 为准。

## 总体判断

Studio 已完成 Project 素材 → 分镜脚本 → 真实旁白 → 画面匹配 → 共享渲染预览 → MP4 的制作闭环。提升重点是全片制作效率、提前发现问题和失败后继续制作。维持 DSH 唯一 harness、browser 唯一工具、Project 归属和 revision 冲突保护。

## 全流程审视

| 环节 | 已有能力 | 主要缺口 | 本轮处理 |
|---|---|---|---|
| 准备素材 | 文本/图像/音视频、笔记与大纲、零分镜草稿 | 准备素材可用性不等于成片可用性 | 成片检查只检查实际绑定素材，保留材料库 |
| 分镜脚本 | 全片与当前分镜同步、增删排序、来源与画面要求 | 全片状态分散，需要逐段检查 | 统一总长、时间轴、待制作数量及分镜问题 |
| 旁白制作 | 真实 Edge/本地 TTS、实测时长、参数溯源与 stale 检测 | 逐段制作成本高，中断后需手动排查 | 批量待制作旁白、逐段保存、可续作、在线策略一致 |
| 画面匹配 | 缩略图、拖放、取景/速度/起点、缺口与显式定格 | 已编辑时长不等于真实覆盖；无效起点可能被 hold 掩盖 | 实测覆盖检查，拒绝空源区间，定格 warning |
| 音频与字幕 | 旁白/原声混音，独立字幕时间/样式 | 较短再配音或音频绑定可能使字幕越界 | 时长保留字幕终点，继续遵守分镜/全片上限 |
| 预览与导出 | 音频时钟、共享 Canvas/Mediabunny 渲染、H264/AAC、版本记录 | 素材失败通常到导出时才出现 | 提前只读检查，汇总定位，导出复用同一准入 |
| 状态与边界 | CAS revisions、取消、FIFO、Project/Session 校验 | 多段后台工作更易覆盖手动编辑 | 每段提交复核 revision，拒绝取消后的迟到结果 |

## 已实施的验收标准

1. GUI 与 browser video.studio 均可执行 check/narrate-pending，未新增模型工具或执行循环。
2. 批量只制作缺失/过期且非空的脚本；有效导入/生成音频不重做。中断保留已完成段，使用最新 revision 可续作。
3. check 不写草稿，返回可定位问题；共享音视频只探测一次；缺失文件、链接、不可解码/透明/超大视频阻止导出。
4. check/导出以真实时长判定覆盖，源起点越界时 hold 不能绕过；有效末帧定格允许导出并提示。
5. 短音频再生成/绑定保留独立字幕终点；超出 60 秒/180 秒限额明确失败，不覆盖现有录音绑定。
6. 覆盖单元/契约、Electron GUI、真实预览/导出及完整离线回归；证据记录见 VERIFICATION.md。

## 后续演进顺序与本次实施

| 优先级 | 能力 | 进入条件与验收 |
|---|---|---|
| P1 | 原生图片检查与统一解码预算 | 在 media-native 增加受限图片探测端口，测试真实解码、尺寸/像素限制与取消；已实施：真实 PNG/JPEG/WebP 解码、32 MiB/16MP 单图与全片 256 MiB/32MP 预算、取消恢复 |
| P1 | 字幕导出与实测对齐 | 已实施 Project SRT/VTT、累计时间、edited/estimated/mixed 来源；已评估本地模型仅有合成，没有可验证的对齐能力，自动逐词对齐留待可靠模型与独立验收 |
| P2 | 单分镜多段画面与转场 | 已实施每分镜最多 8 片段、独立源参数、cut/fade、GUI 编辑和连续旁白/字幕，共享预览/导出与分段原声 |
| P2 | 内容生产辅助 | 已实施脚本/已有素材匹配入口、Project 受限文字读取，复用当前 DSH Session/唯一 browser，并检查 revision；真实模型质量另验收 |
| P3 | 编码预检与成片验收报告 | 已实施原生 H.264/AAC 编码预检、输出实际轨道/尺寸/采样率/时长复读、Project JSON 验收报告和下载 |

本次按上述顺序完成可验收能力。fade 是经过背景的淡出/淡入；不扩展为通用 NLE。字幕依然是编辑或估算时间，未加入自动逐词对齐。当前安装的本地 Matcha 仅提供语音合成；后续引入对齐器需有固定模型、许可证/预算/取消契约，并以真实中英音频测试误差。确定性 TTS 与 Assistant 接收替身只验证路由，真实本地 TTS另测；外部 Edge、付费模型和生产配置不属于离线覆盖。
